# Perpustakaan Digital Online

## Jalankan di laptop
1. Install Node.js 18+.
2. Buka terminal di folder ini.
3. Jalankan `node server.js`.
4. Buka `http://localhost:3000`.

JANGAN membuka `public/index.html` langsung. Login memakai API server.

Akun demo siswa: siswa@sekolah.id / siswa123
Akun demo pengurus: pengurus@perpus.id / admin123

## Online untuk banyak siswa
Upload folder ke hosting yang mendukung Node.js dan jalankan `node server.js`. Untuk pemakaian sungguhan, ganti akun demo dan gunakan database server (PostgreSQL/MySQL) serta HTTPS.
